4SQUARE CLOCK

Update your 4square

This puts the newest software on your clock and sets it to the right time. It takes about two minutes.

Before you start

  1. Use Chrome or Edge on a Mac or Windows computer. Safari and Firefox cannot do this.
  2. Use a USB-C cable that carries data. Some cables only charge; if the clock does not show up, try another cable.
  3. Plug the clock into this computer with that cable.
  4. Click the green button. In the list that opens, pick USB JTAG/serial debug unit and press Connect. (On Windows it may say USB Serial Device.)

This browser cannot update the clock

Open this page in Chrome or Edge on a Mac or Windows computer. Safari, Firefox and phones cannot talk to the clock over USB.

Already updated? “Just set the clock” only sets the time.

  1. Connect
  2. Install
    0%
  3. Restart
  4. Set clock
  5. Done

One more click

Your clock restarted, and the browser wants you to pick it once more. Click the button below, pick USB JTAG/serial debug unit again, and press Connect.

If something goes wrong

Nothing shows up in the list

The cable is probably a charge-only cable. Try a different USB-C cable, or a different USB port on the computer. Then click the button again.

The install stops partway

Unplug the clock, plug it back in, and click Update my 4square again. Nothing is broken; a full install fixes it.

The page says this browser cannot do it

Open this page in Chrome or Edge on a Mac or Windows computer. Safari, Firefox and phones cannot talk to the clock over USB.

The time is wrong

The clock copies this computer’s time. Check that the computer shows the right time, then click Just set the clock.
